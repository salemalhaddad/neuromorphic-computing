This is a collection of my notes, implementations, and code around **neuromorphic computing**, from the neuroscience, to the early implementations like Misha Mahowald's sensor, to recent engineering applications by [iniVation](https://inivation.com/) and [prophesee](https://www.prophesee.ai/).

This repo tries to deep dive into neuromorphic computing through the history of the original papers by implementing some of them.

_Inspired by Adam Majmudar's [Deep Dives](https://adammaj.com/deep-dives)._
